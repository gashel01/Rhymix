> A TypeScript copy of every module in this folder used to sit beside the
> JavaScript one. It never ran: Create React App resolves `.js` before `.ts`
> and `.tsx`, so the `.js` files always won — and they had been developed
> further (926 lines against 403). The TypeScript originals have been removed
> and this note left in their place, because the folder read as if they were
> the live ones.
